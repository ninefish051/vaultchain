## 6. 踩过的坑（已修复）

| 现象 | 原因 | 处理 |
|---|---|---|
| 新加坡区所有调用 `explicit deny in a service control policy` | 组织 SCP 只放行悉尼 | 全部改到 `ap-southeast-2` |
| RDS 创建失败：backup retention exceeds the maximum for free tier | 账号是 Free 计划 | 备份保留改为 1 天；EC2 改 t3.small |
| cfn-lint 报 `EngineVersion '16'` 不能新建 | RDS 要完整小版本号 | `deploy-stack.sh` 首次创建时自动查询默认 16.x |
| 开机脚本 `KeyError: 'DOMAIN'` | `/etc/vaultchain.env` 没 export | `set -a; source; set +a` |
| 修复后重跑仍报同样错误 | 脚本先执行后 `git pull`，跑的是旧版本 | 拉完代码后 `exec` 新版本重跑自己 |
| 容器起不来：CreateLogStream AccessDenied on `/vaultchain/infra` | Compose 把项目名设成目录名 `infra` | 日志组名写死 `/vaultchain/prod` |
| `cast send` 报 `peer closed connection without sending TLS close_notify` | RPC 连接被断（网络/代理） | 直接重试；交易没发出不会重复扣钱 |
| 保存收货地址失败 | `SHIPPING_ENC_KEY` 从没生成（`put-secrets.sh` 没跑过） | 生成随机 32 字节写入 `vaultchain/prod` |
| 本机终端 `cast: command not found` | 安装后没重开终端 | 用 `~/.foundry/bin/cast` 或新开终端 |

## 7. 安全要点

- **仓库是公开的**：任何私钥、密码、API key 都不能提交；只放在 Secrets Manager 或本机 keystore。
- 部署钱包是所有合约的管理员，keystore 密码丢了只能重新部署。
- `vaultchain-admin` 是全权限长期 key：建议开 MFA、定期轮换。
- RDS 只允许服务器安全组访问；服务器不开 SSH。
- 两个服务热钱包只放少量 gas。
