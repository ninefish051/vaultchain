# VaultChain 手动测试用例（HSK 测试网）

> 测试站点：https://vaultchain.asia · 网络：HashKey Chain Testnet（chain 133）
> 自动化端到端脚本（`e2e:testnet`）已覆盖托管买卖和卡对卡交换的合约与 API 层，15/15 通过。
> **本清单验证的是网页上的真人操作**，带 ⚠️ 的预期结果是按代码推断、还没在网页上实际走过，测试时请重点确认。

---

## 0. 测试准备

### 0.1 三个角色、三个钱包

| 角色 | 用途 | 钱包 |
|---|---|---|
| **A 卖家** | 挂单、发货、收款 | MetaMask 新建账户 A |
| **B 买家** | 下单、付款、收卡 | MetaMask 新建账户 B |
| **V 金库员** | 入库、验货 | 导入测试金库员 `0xdc83Ec0b2588fD3Ad7d41a844EF87f1B8639CcF4` |

建议 A、B 用两个浏览器（或一个普通窗口 + 一个无痕窗口），V 可以和 A 共用一个浏览器、在 MetaMask 里切换账户。

**导入金库员私钥**：在**自己的终端**运行，不要贴到任何聊天里：
```bash
aws secretsmanager get-secret-value --secret-id vaultchain/e2e --query SecretString --output text | python3 -c "import json,sys; print(json.load(sys.stdin)['VAULT_KEY'])"
```
MetaMask → 添加账户 → 导入账户 → 粘贴。测试结束后可以从 MetaMask 移除。

### 0.2 MetaMask 添加网络

| 字段 | 值 |
|---|---|
| 网络名称 | HashKey Chain Testnet |
| RPC URL | `https://testnet.hsk.xyz` |
| Chain ID | `133` |
| 货币符号 | `HSK` |
| 区块浏览器 | `https://testnet-explorer.hsk.xyz` |

### 0.3 Gas（HSK）

- A、B：分别到 https://faucet.hskchain.net/faucet 领（每个地址 24 小时一次，约 0.1 HSK，够做几十笔交易）。
- V：现有约 0.0045 HSK，够十几笔；不够时用部署钱包转：
  `~/.foundry/bin/cast send 0xdc83Ec0b2588fD3Ad7d41a844EF87f1B8639CcF4 --value 0.01ether --rpc-url https://testnet.hsk.xyz --account vaultchain-deployer`

### 0.4 记录方式

每条用例记录：**通过 / 不通过 / 阻塞**，不通过时截图 + 浏览器控制台报错 + 交易哈希（MetaMask 活动里能看到）。

### 0.5 已知现象（不算 bug）

- 浏览器控制台有 2 条 403 / 400 报错：WalletConnect 用的是占位 project ID，**扫码连接不可用**，插件钱包正常。
- 卡片价格是**合成的演示价格**（price-indexer 还没有真实数据源）。
- 挂单会显示"未验证"：没有配置 `PSA_API_TOKEN`。
- Agent 暂不测试：导航里已隐藏入口（/agent 地址仍可直接打开）。

## 2. 金库入库与一口价（金库 NFT）

### TC-06 金库员入库并铸 NFT 给卖家
| | |
|---|---|
| 前置 | 账户 V 已连接 |
| 步骤 | 1. 打开 `/vault` 2. Intake 区选一张卡（如 Charizard PSA 10），Grader 选 PSA，证书号填一个新的 8 位数（如 `70000001`），Owner 填 **A 的地址** 3. 点 **Register & mint NFT**，确认交易 |
| 期望 | 交易成功；A 连接后在 **My cards** 页看到这张卡（PSA 70000001） |
| 注意 | 证书号每次测试都换新的；同一个证书号不能重复铸造 |

### TC-07 卖家把金库 NFT 挂一口价
| | |
|---|---|
| 前置 | TC-06 完成 |
| 步骤 | 1. A 打开 **Sell** 2. 选 **A vault NFT** 3. 选刚才那张卡 4. 填价格（接近公允价，如公允价 ±5%） 5. 点 **List for $…**，依次确认 "Approve marketplace" 和 "Listing" 两笔交易 |
| 期望 | 提示 "Listed. Buyers can purchase it instantly."；Market 里该卡出现这条挂单 |

### TC-08 买家一口价购买
| | |
|---|---|
| 前置 | TC-07 完成；B 有足够测试 USDC |
| 步骤 | 1. B 打开该挂单 2. 点 **Buy now · $…** 3. 确认 "Approve USDC"（首次）和 "Buying" |
| 期望 | 交易成功；B 的 **My cards** 出现这张卡；A 的 My cards 不再有；挂单从 Market 消失；A 的 USDC 余额增加（价格 − 1% 手续费） |

## 3. 托管买卖（实物卡，主流程）

> 时间窗口：押金 24 小时、发货 3 天、验货 2 天、付款 2 天。押金比例 = clamp(10% + 2×波动率, 10%, 30%)。

### TC-09 卖家挂实物卡
| | |
|---|---|
| 步骤 | 1. A 打开 **Sell** → 选 **A slab I hold** 2. 选卡（如 Blastoise PSA 10）、Grader PSA、填新证书号（如 `70000002`）、价格（接近公允价）、可选自动接受底价 3. 勾选/不勾选 "Open to card-for-card swaps" 4. 点 **List for $…** |
| 期望 | 提示 "Listed. When a buyer signs an order you'll find it under Orders…"；Market 里能看到；**不需要链上交易**（只签名） |

### TC-10 买家签署托管订单
| | |
|---|---|
| 步骤 | 1. B 打开该挂单 2. "After the check" 点选 **Keep in vault** 卡片 3. 点 **Buy with escrow**，MetaMask 弹出签名（不是交易，不花 gas） |
| 期望 | 提示 "Signed order sent to the seller. Once they countersign, you lock your deposit from Orders." |

### TC-11 卖家会签并创建链上订单
| | |
|---|---|
| 步骤 | 1. A 打开 **Orders** → "Waiting for signatures" 2. 找到 B 的订单，点 **Countersign & create**，确认签名和交易 "Creating escrow order" |
| 期望 | 交易成功；订单进入 Escrow orders 列表，状态 Signed；Market 里这条挂单**消失**（已被预订，几秒到一分钟内） |

### TC-12 同一张卡不能再被下单
| | |
|---|---|
| 步骤 | 换另一个账户（或 B 再来一次）对同一张卡走 TC-10、TC-11 |
| 期望 | ⚠️ 挂单已不在 Market；若强行用旧链接签单，会签时合约拒绝（报错含 `SlabBusy`） |

### TC-13 双方锁押金
| | |
|---|---|
| 步骤 | 1. B 打开订单详情，"Your next step" 显示 **Lock your deposit: $…**，点击并确认 Approve USDC + "Locking deposit" 2. A 同样操作 |
| 期望 | 两边押金金额相同；双方都付完后状态变成 **Locked**；USDC 余额相应减少 |

### TC-14 买家填写收货地址 / 权限
| | |
|---|---|
| 步骤 | 1. B 在订单详情填写收货地址并保存 2. A 尝试查看或填写这个订单的收货地址 |
| 期望 | B 保存成功；A **不能**看到 B 的地址（被拒 403） |
| 补充 | 若 TC-10 选的是 **Ship to me** 卡片，V 在 `/vault` 点 **View address** 能看到地址 |

### TC-15 卖家发货
| | |
|---|---|
| 步骤 | A 在订单详情输入 "Courier + tracking number"（如 `SF 1234567890`），点 **Mark as shipped**，确认交易 |
| 期望 | 状态变成 **Inspecting**；链上只存运单号的哈希 |

### TC-16 金库验货通过
| | |
|---|---|
| 步骤 | 1. V 打开 `/vault`，在待验货队列找到这笔订单 2. 可填 Inspection report 3. 点 **Pass**，确认交易 |
| 期望 | 状态变成 **PaymentWindow**；B 的下一步变成 **Pay the full price: $…** |

### TC-17 买家付全款
| | |
|---|---|
| 步骤 | B 点 **Pay the full price**，确认 "Paying" |
| 期望 | 状态 **Completed**，"Your next step" 显示 "Deal done" 成功卡片和 **See my cards** 链接；B 的 My cards 出现这张卡（NFT，证书号 70000002）；挂单不再出现在 Market |

### TC-18 双方提现
| | |
|---|---|
| 步骤 | 1. A 打开订单详情（或 Orders），看到 "Available to withdraw" 2. 点 **Withdraw USDC** 3. B 同样操作 |
| 期望 | A 可提现 = **价格 − 1% 手续费 + 自己的押金**；B 可提现 = **自己的押金**；提现后余额归零、USDC 余额增加 |

### TC-19 验货不通过
| | |
|---|---|
| 步骤 | 新开一单走到 TC-15，V 在 `/vault` 点 **Fail** |
| 期望 | 状态变成 **Disputed**；需要仲裁（仲裁权限在部署钱包，测试员不处理，记录状态即可） |

### TC-20 未付押金时取消
| | |
|---|---|
| 步骤 | 新开一单走到 TC-11（Signed），任一方在订单详情点 **Cancel and refund deposits** |
| 期望 | 押金期限（24 小时）**未到时**点取消，交易被拒，报错 `DeadlineNotReached`；**期限过后**取消成功，状态 **Cancelled**，已付的押金退回。明天测试只验证"未到期被拒"这一半，到期那一半第二天再看 |

### TC-21 出价 / 还价 / 接受
| | |
|---|---|
| 步骤 | 1. B 在某条实物挂单点 **Make an offer**，出低于挂价的价格 2. A 在该挂单的 Offers 里分别试 **Counter**（还价）、**Accept** |
| 期望 | 出价出现在 A 的 Offers 里；还价后 B 能看到新价格；接受后 B 以约定价格进入签单流程（TC-10） |
| 补充 | 若出价 ≥ 卖家设置的自动接受底价，⚠️ 应直接被接受 |

## 4. 卡对卡交换

### TC-22 实物卡 ⇄ 金库 NFT（补差价）
| | |
|---|---|
| 前置 | A 有一张金库 NFT（用 TC-06 再铸一张，如 Venusaur PSA 10），并把它挂单且勾选 "Open to card-for-card swaps" |
| 步骤 | 1. B 打开 **Swap** → "One or both cards still physical" → 选 A 的那张卡，进入 **Propose a swap** 2. "You give" 选 **A slab I hold**，填卡、Grader、新证书号（如 `70000003`） 3. 选择收到后 Keep in vault 4. 点 **Sign swap proposal** 5. A 在 Orders → Waiting for signatures 点 **Countersign & create** 6. A 确认 "Approve NFT for swaps"；双方各自在交换详情锁押金（便宜那张卡的一方还要付差价） 7. B 输入运单号并标记发货 8. V 在 `/vault` 对 B 的那一边点 **Pass** |
| 期望 | 交换状态最终 **Completed**，页面显示 "Swap done" 成功卡片和 **See my cards** 链接；B 拿到 A 的 NFT，A 拿到一张新铸的 NFT（证书号 70000003）；差价进入收款方的 "Available to withdraw" |
| 参考 | 自动化测试里：Blastoise $3,135 换 Venusaur $2,538，卖家补 $596.72 |

### TC-23 两张都在金库的 NFT 互换
| | |
|---|---|
| 前置 | A、B 各有一张金库 NFT（TC-06 铸给 B 一张） |
| 步骤 | 1. B 进 Swap → "Both cards in the vault" → 选 A 的卡 2. You give 选 **A vault NFT** 3. 点 **Create swap offer**，确认授权和交易 4. A 接受这个报价 |
| 期望 | ⚠️ 两张 NFT 当场互换（原子交换），各收一笔固定手续费（$5/方）；不需要验货 |
