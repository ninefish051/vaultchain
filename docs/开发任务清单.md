### 0.1 当前完成度（一句话版）

合约已部署到 HSK 测试网，服务跑在 AWS 悉尼，前端在 vaultchain.asia；**托管买卖和卡对卡交换已经端到端跑通**（自动化 15/15）。**还没做**：HSP 真实付款联调、买家 Agent、真实价格数据、主网部署、比赛提交材料。

### 0.2 工作约定（必须遵守）

- **仓库是公开的**：任何私钥、密码、API key 都不能写进代码、文档或提交记录。密钥只放 AWS Secrets Manager（`vaultchain/prod`、`vaultchain/e2e`）或本机 keystore。
- **部署钱包（合约管理员）的 keystore 只有项目负责人能解锁**。凡是需要管理员签名的链上操作（授权角色、转 gas、部署合约），写好命令交给负责人在自己终端执行。
- AWS 只能用 **ap-southeast-2（悉尼）**；账号是 Free 计划，EC2 只能用免费套餐机型。
- 本机 AWS CLI 用 profile `vaultchain`。
- 改完服务端：推到 `main` → `./infra/aws/redeploy.sh`（服务器从 main 拉代码）。
- 改完前端：按 `docs/部署与运维手册.md` §4.6 的命令重新构建部署（`NEXT_PUBLIC_*` 是构建时写死的）。
- 每次改动合约或服务后跑回归：`pnpm --filter @vaultchain/api e2e:testnet`，必须 15/15 通过。
- 本地检查：`pnpm typecheck && pnpm test`；合约 `cd contracts && forge test`。CI（GitHub Actions）在每次推送时跑这些。
- 提交信息用英文，说明做了什么、为什么。
